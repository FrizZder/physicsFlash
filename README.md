# PhysicsFlash

Интерактивное веб-приложение для изучения физики с помощью карточек и интерактивных симуляций

## Описание проекта

PhysicsFlash – это образовательное веб-приложение, которое помогает изучать основные понятия, формулы и законы физики с помощью интерактивных карточек и физических симуляций. Приложение предназначено для студентов, школьников и всех, кто интересуется физикой.

## Быстрый запуск

### Предварительные требования

- [Node.js](https://nodejs.org/) версии 14 или выше
- npm (поставляется вместе с Node.js) или [yarn](https://yarnpkg.com/)

### Windows

```
git clone https://github.com/yourusername/physics-flash.git
cd physics-flash
npm install
npm start
```

### macOS

```
git clone https://github.com/yourusername/physics-flash.git
cd physics-flash
npm install
npm start
```

### Linux

```
git clone https://github.com/yourusername/physics-flash.git
cd physics-flash
npm install
npm start
```

После запуска приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000) в вашем браузере.

## Основные возможности

- **Интерактивные карточки**: Двусторонние карточки с вопросами и ответами по разным разделам физики
- **Разделы физики**:
  - Механика (14 карточек)
  - Термодинамика (14 карточек)
  - Электродинамика (17 карточек)
  - Оптика (15 карточек)
  - Квантовая физика (19 карточек)
  - Астрономия (16 карточек)
- **Интерактивные физические симуляции**:
  - Маятник (колебания и период)
  - Баллистическое движение (траектория тела под углом к горизонту)
  - Столкновения и закон сохранения импульса
  - Гравитационное взаимодействие и орбиты
  - Волновые процессы
  - Электрическое поле
  - Пружинная система
  - Идеальный газ
- **Режимы обучения**:
  - Режим обучения: последовательное изучение карточек
  - Режим тестирования: проверка знаний с отслеживанием правильных и неправильных ответов
  - Игровой режим: обучение с таймером и подсчетом очков для повышения мотивации
- **Система отслеживания прогресса**:
  - Визуализация общего прогресса обучения
  - Статистика по разделам физики
  - Отслеживание освоенных карточек
  - Счетчик правильных и неправильных ответов
- **Математические формулы**:
  - Поддержка LaTeX-разметки с помощью KaTeX
  - Красивое отображение сложных физических формул
- **Дополнительные функции**:
  - Добавление карточек в избранное
  - Фильтрация по уровню сложности
  - Специальная страница для просмотра всех физических симуляций
  - Экран результатов после прохождения тестирования
  - Темная и светлая темы оформления

## Технологии

- React 18
- TypeScript
- React Router v6
- Styled Components
- KaTeX для рендеринга математических формул
- Matter.js для физических 2D-симуляций
- LocalStorage для сохранения прогресса пользователя

## Структура проекта

- `/src/components` - React компоненты
  - `/Card` - Компоненты для отображения карточек
  - `/Formula` - Компоненты для рендеринга формул
  - `/Navigation` - Компоненты навигации (хедер, футер)
  - `/Progress` - Компоненты для отслеживания прогресса
  - `/Simulation` - Компоненты физических симуляций
- `/src/pages` - Компоненты страниц
  - `HomePage` - Главная страница
  - `CardsPage` - Страница с карточками
  - `FavoritesPage` - Страница с избранными карточками
  - `StatsPage` - Страница статистики
  - `SimulationsPage` - Страница с физическими симуляциями
- `/src/styles` - Глобальные стили
- `/src/data` - Данные карточек
  - `/flashcards` - Карточки по разделам
  - `simulationCards.ts` - Карточки с симуляциями
- `/src/services` - Сервисы приложения
  - `cardService.ts` - Сервис для работы с карточками
  - `progressService.ts` - Сервис для отслеживания прогресса
- `/src/types` - TypeScript типы и интерфейсы

## Интерактивные симуляции

PhysicsFlash включает в себя 8 типов физических симуляций, реализованных с помощью библиотеки Matter.js:

1. **Маятник**: Демонстрирует гармонические колебания и зависимость периода от длины маятника
2. **Баллистическая траектория**: Показывает движение тела, брошенного под углом к горизонту
3. **Столкновения**: Иллюстрирует закон сохранения импульса при столкновении тел
4. **Гравитация**: Моделирует гравитационное взаимодействие и движение по орбитам
5. **Волны**: Демонстрирует распространение волн в среде
6. **Электрическое поле**: Показывает взаимодействие заряженных частиц
7. **Пружинная система**: Иллюстрирует колебания пружинного маятника
8. **Идеальный газ**: Моделирует поведение молекул в идеальном газе

## Система отслеживания прогресса

Приложение включает усовершенствованную систему отслеживания прогресса:

- Сохранение прогресса в localStorage
- Расчет процента изученного материала по каждому разделу
- Индикаторы общего прогресса в шапке приложения
- Подробная статистика на отдельной странице
- Выделение освоенных карточек
